# Supreme Diplomat

Crusader Kings III diplomacy mod. Version 0.3.0. Supported game version 1.20.*.

Embrace the Supreme Diplomat trait to offer vassalage, bind tributaries, seal alliances and marriage pacts, sway courts, invite small realms, adopt liege government across mismatched vassals (Feudal↔Clan), and grow a federation network — prestige and sweeteners, not conquest CBs or hooks.

Canonical working copy (when Windows is online): `Documents/Development/CK3 Mods/sd` (+ outer `sd.mod`). GitHub is source of truth for this ship.

Soft peers: Supreme Sovereign, Supreme Schemes, Exalted Advisor, Succession Unity Soft Glue, Exalted Dynasty/Culture/Faith, Death Stare (detection / tooltips only; no hard dependency).

Prefix: `sd_`. Additive only; no `replace_path`.
